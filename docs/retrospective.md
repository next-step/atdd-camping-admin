## T-1 작업 회고

### 인수 테스트 초안 판정

- 판정: 수정 후 채택
- 콘솔 `POST` 초안을 요구 대상인 REST `PUT /admin/products/{id}`로 바꾸고, HTTP 200 응답 본문과 별도 조회 결과를 나눠 검증하도록 수정한 뒤 채택한다.
- 이름만 수정하는 회귀 테스트에서 응답 이름 단언은 영속화를 증명하지 않고 인수 조건 밖 동작을 고정하므로 제거하고, HTTP 상태와 재고·가격 보존만 검증하도록 수정했다.


### 절차를 알아서 빨라진 것

- 수정 응답만 보지 않고 수정 뒤 별도 조회로 영속화를 확인해야 한다는 절차를 알고 있어, 응답은 바뀌지만 저장되지 않는 증상을 바로 구분했다.
- 로그인 JWT와 `@Sql` 격리 방식을 먼저 정해 인수 테스트의 인증·데이터 준비를 반복해서 탐색하지 않았다.

### 이번에 덜 판 것

- T-1을 REST 재고 수정으로 제한하고, 입력값 검증 정책과 콘솔 수정 및 다른 필드의 영속화는 T-2와 T-3으로 미뤘다.
- 구현 단계는 진행하지 않아 실제 저장 누락의 수정 방법과 변경 후 회귀 범위는 다루지 않았다.
