T-1 상품 수정이 저장되지 않음
내용: 운영팀 신고 — "관리자 화면에서 상품 재고를 수정했는데, 저장했다고 나오고선 값이 그대로입니다."
---

T-2 상품 재고 수정 입력 검증 정책 확인 필요
내용: 관리자 상품 수정에서 재고가 음수, 누락, 빈 값, 공백, 정수가 아닌 값 또는 `null`일 때 허용 여부와 HTTP 상태·오류 메시지·기존 값 유지 여부를 운영 입력 정책과 함께 확정한다.
---

T-3 콘솔 상품 수정과 REST의 재고 외 필드 영속화 범위 확인 필요
내용: `POST /console/products/{id}`에서 수정하는 필드와 `PUT /admin/products/{id}`에서 이름·가격·상품 타입을 수정하는 경우의 영속화 범위를 별도 인수 조건과 직접 호출로 확인한다. T-1은 REST 재고 수정과 이름만 보낼 때 재고·가격 보존만 다룬다.
