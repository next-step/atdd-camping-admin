# 인수 조건

## T-1 상품 수정이 저장되지 않음

```
규칙   상품 정보를 수정하면 그 변경 내용이 저장되어, 이후 조회 시 변경된 값으로 나와야 한다
이유   운영팀이 재고·가격 등을 수정해도 반영되지 않으면, 화면에 보이는 값과 실제 값이
       어긋나 잘못된 안내(품절 상품을 판매 가능으로 표시 등)로 이어진다

Given  상품(id=1)의 이름이 "랜턴"이다
When   이름을 "랜턴-수정됨"으로 수정해 저장한다    Then  302, 조회 시 "랜턴-수정됨"으로 나와야 하나 실제로는 "랜턴" 그대로 (변경 안 됨)
```
